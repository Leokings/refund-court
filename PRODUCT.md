# Refund Court
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
User specified Next.js App Router, strict TypeScript, Vercel remote build; GenLayer StudioNet 61999 and x402 on Base Sepolia.

## Users
AI agent builders buying API calls; API sellers posting enforceable promises; Internet Court mission reviewers inspecting live evidence without a wallet.

## Product Purpose
Chargebacks for agents. Validators compile a seller's plain-English promise and judge paid, signed API responses. A breached promise refunds the buyer's full USDC payment on Base Sepolia from the seller's bond.

## Constraints
Works on desktop and phones. Zero mocked live proof. Response bodies are untrusted. Six real finalized cases. Test-USDC spending requires owner approval. No automatic Portal submission. Separate recorded proof from current chain reads. All transactions expose final execution success separately from consensus finality.

## Brand Commitments
Refund Court; “Chargebacks for agents.” One Built for Internet Court note. Internet Court, GenLayer and x402 logos in demo video script.

## Evidence
Official Internet Court skill and x402 SDK documentation read on November 12, 2026. Live support response saved under docs/research. All deployment claims must be backed by deploy/proof.json and chain receipts.

## Design assumptions
Design decisions delegated by the user's explicit instruction to work autonomously. Assume reviewers use a desktop or phone browser, with no wallet needed for reading.
